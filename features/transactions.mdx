---
title: "Transactions and inspection"
description: "Inspect Sandbox resources and request a fresh Production provider overview."
---

Sandbox Payments, refunds, wallets, and transfers are simulated resources and can be listed in the dashboard or through the financial APIs.

Production provider transactions are not an OurPocket transaction history. Select a connected provider in the Production overview to fetch a live, uncached summary of safe operational fields: references, statuses, amounts, currencies, timestamps, bank names, and masked account numbers. The response is shown for the current request only and is never written to resources, logs, events, queues, or snapshots.

The overview keeps local API-usage metrics separate from provider activity. It can report section-level unavailability when a provider product is not enabled or a provider call fails.
