OurPocket gives your application one interface for creating wallets, moving balances, choosing payment providers, and tracking transaction outcomes.

## What you can build

<CardGroup cols={2}>
  <Card title="Customer wallets" icon="wallet">
    Create project-scoped wallets for your users and retrieve their current ledger balance.
  </Card>
  <Card title="Credits and debits" icon="arrow-right-arrow-left">
    Add or remove value through ledger-only operations or a supported provider.
  </Card>
  <Card title="Wallet transfers" icon="money-bill-transfer">
    Transfer value between wallets that belong to the same project and currency.
  </Card>
  <Card title="Provider routing" icon="route">
    Select Paystack or Flutterwave directly, or provide routing inputs for OurPocket to choose one.
  </Card>
  <Card title="Durable transactions" icon="receipt">
    Submit credit, debit, and transfer requests with stored `pending`, `success`, or `failed` status.
  </Card>
  <Card title="Project environments" icon="key">
    Separate test and live credentials for every project.
  </Card>
</CardGroup>

## Typical integration flow

<Steps>
  <Step title="Create a project">
    Use a project to isolate credentials, providers, wallets, transactions, and usage for one product.
  </Step>
  <Step title="Prepare a project key">
    Use the test key while developing and the live key for intended production traffic.
  </Step>
  <Step title="Choose provider behavior">
    Send ledger-only operations, select a provider directly, or provide routing metadata.
  </Step>
  <Step title="Create customer wallets">
    Associate wallets with your own customer identifiers and chosen currencies.
  </Step>
  <Step title="Move value">
    Use direct wallet operations or durable transactions depending on your tracking requirements.
  </Step>
</Steps>

## Dashboard and API

The dashboard helps you prepare and inspect integrations. Your application communicates with the runtime API using a project API key.

| Use the dashboard for | Use the API for |
| --- | --- |
| Projects and active project selection | Wallet creation and lookup |
| Project keys | Credits, debits, and transfers |
| Provider catalog and connections | Durable transaction submission |
| Request testing consoles | Transaction retrieval |
| Webhook registration | Normalized provider-event ingestion |
| Usage overview | Application integration |
