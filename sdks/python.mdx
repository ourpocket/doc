---
title: "Python integration"
description: "Use the normalized HTTP API from Python."
---

There is no maintained Python SDK for the normalized financial API. The older Python example client in this repository targets compatibility wallet routes and should not be used as a new integration. Call the [HTTP endpoints](/reference/endpoints) with a server-side `op_test_sk_` or `op_live_sk_` key, JSON bodies, and an `Idempotency-Key` for creations. Keep amounts as integer minor-unit strings.

Start with [the Sandbox quickstart](/quickstart) and [response conventions](/reference/api-conventions). A provider timeout can leave an `unknown` resource; do not automatically repeat a financial write.
