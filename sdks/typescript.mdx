---
title: "TypeScript SDK"
description: "Use the standalone typed client for Sandbox and stateless provider operations."
---

The source package is `packages/typescript` and exports `@ourpocket/sdk`. Run `npm run check`, `npm test`, and `npm run build` from that directory before linking it into a server application.

```ts
import { OurPocket } from "@ourpocket/sdk";

const pocket = new OurPocket({ apiKey: process.env.OURPOCKET_API_KEY! });

const checkout = await pocket.payments.create(
  {
    amount: "50000",
    currency: "NGN",
    provider: "paystack",
    reference: "order_4821",
    contact: { email: "buyer@example.com" },
  },
  { idempotencyKey: "sandbox-only-key" },
);

const overview = await pocket.paystack.overview({ limit: 10 });
```

The client exposes typed `paystack` and `flutterwave` namespaces for account resolution, recipients or beneficiaries, payouts, virtual accounts, and live overview reads. Mono is accepted for DirectPay checkout and verification. Provider writes do not retry automatically and their results are never stored by OurPocket. Keep references and results in your system.
