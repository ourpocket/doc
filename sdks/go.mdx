---
title: "Go integration"
description: "Use the normalized HTTP API from Go."
---

There is no maintained Go SDK for the normalized financial API. The older Go example client targeted compatibility wallet routes. Call the [HTTP endpoints](/reference/endpoints) from your server with a project key, JSON, and an `Idempotency-Key` for creations. Represent monetary amounts as decimal strings of integer minor units, not floating-point values.

Start with [the Sandbox quickstart](/quickstart) and [response conventions](/reference/api-conventions). Verify Production hosted checkout before settlement.
