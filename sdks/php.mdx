---
title: "PHP integration"
description: "Use the normalized HTTP API from PHP."
---

There is no maintained PHP SDK for the normalized financial API. The older PHP example client targeted compatibility wallet routes. Call the [HTTP endpoints](/reference/endpoints) from your server with a project key, JSON, and an `Idempotency-Key` for creations. Keep amounts as integer minor-unit strings.

Start with [the Sandbox quickstart](/quickstart) and [response conventions](/reference/api-conventions). Inspect `unknown` outcomes instead of blindly retrying a financial write.
