OurPocket exposes a JSON REST API that works with any server-side HTTP client.

<Note>
  Official installable SDK packages are not published in this repository yet. The guides in this section provide small, reusable client wrappers around the real API so you can integrate today without depending on an unavailable package.
</Note>

## Shared configuration

Every language client needs:

```text
OURPOCKET_BASE_URL=https://your-ourpocket-api.example/v1
OURPOCKET_API_KEY=your-project-api-key
```

Run these clients only in trusted server environments. Do not embed project or provider credentials in frontend JavaScript or mobile binaries.
