---
title: "Move to Production"
description: "Connect and validate a provider account before making live requests."
---

1. Keep Sandbox test data separate; it does not migrate to Production.
2. Connect a Paystack, Flutterwave, or Mono account while Production is selected.
3. Provide the configured callback URL, webhook secret, and live credentials required by that provider. Validation checks access without moving money.
4. Create and store an `op_live_sk_` key on your server.
5. Send a caller-owned provider reference, transient contact data where required, and a callback URL for Flutterwave or Mono checkout.
6. Configure provider webhooks directly in the provider dashboard and retain provider results in your own system.

OurPocket returns live provider results but does not retain them, so use your application and provider dashboard for verification and reconciliation.
