---
title: "Fund a Sandbox wallet"
description: "Add simulated fiat value without moving real money."
---

Use `POST /v1/sandbox/wallets/{id}/fund` with a Sandbox project key, a new `Idempotency-Key`, and `{ "amount": "20000", "currency": "NGN" }`. The currency must match the wallet. Read `GET /v1/wallets/{id}` to inspect the updated `details.balance`.

Funding creates a normalized operation and event in the project's Sandbox environment. It never calls Paystack, Flutterwave, or the old external ledger. Production rejects this route. See [wallet API examples](/developer-guide/wallet-api) for cURL and [environments](/concepts/environments) for the isolation rules.
