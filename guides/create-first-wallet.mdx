---
title: "Create your first wallet"
description: "Create a simulated fiat wallet with a Sandbox key."
---

Create a project and save its `op_test_sk_` key as shown in [the quickstart](/quickstart). Call `POST /v1/wallets` with `{ "currency": "NGN" }` and a unique `Idempotency-Key`. The response is a completed wallet with `details.balance: "0"`. Read it with `GET /v1/wallets/{id}`.

The [wallet API examples](/developer-guide/wallet-api) show the exact cURL request, funding, and an internal Sandbox transfer. A Production chain wallet is a separate resource shape: connect Turnkey or Privy, use a live key, and provide `provider` and `chain` instead of fiat `currency`. It has an address but no simulated fiat balance.
