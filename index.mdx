## Build with OurPocket

<Steps>
  <Step title="Prepare your project">
    Create an account and workspace, select a project, and prepare a test API key.
  </Step>
  <Step title="Choose provider behavior">
    Start with ledger-only operations or provide Paystack or Flutterwave credentials when provider execution is required.
  </Step>
  <Step title="Create customer wallets">
    Use your own customer ID and currency to create project-scoped wallets.
  </Step>
  <Step title="Move and track value">
    Submit credits, debits, or transfers through durable transactions and store the returned transaction IDs.
  </Step>
</Steps>
