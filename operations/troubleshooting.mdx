---
title: "Troubleshooting"
description: "Inspect failed, pending, and unknown financial operations."
---

First confirm the project and environment. An `op_test_sk_` key cannot read Production resources. Check the `X-Request-Id` response header and the resource's `requestId`, then inspect **API Logs**, **Events**, and **Webhooks** in the matching dashboard environment.

For a `400` response, validate the body and `Idempotency-Key`. Production checkout needs a connected payment provider; with multiple connections, supply an explicit provider or save a routing policy. Flutterwave checkout requires an HTTPS `callbackUrl`. Production chain wallet creation needs connected Turnkey or Privy credentials, a `provider`, and a `chain` rather than fiat `currency`.

For a `pending` payment, complete hosted checkout and verify the original provider. For `unknown`, reuse the original idempotency key and body to fetch the same operation. Verify or run Production reconciliation; never blindly issue a new write. A failed outbound webhook can be inspected in its delivery history and replayed after the endpoint is fixed. See [errors](/reference/errors), [routing](/features/routing), and [webhooks](/user-guide/webhooks).
