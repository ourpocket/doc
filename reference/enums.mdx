---
title: "Financial values"
description: "Use the statuses, scenarios, providers, and environment names returned by the API."
---

| Field | Implemented values |
| --- | --- |
| Environment | `sandbox`, `production` |
| Financial resource kind | `customer`, `payment`, `refund`, `wallet`, `transfer` |
| Operation status | `pending`, `unknown`, `completed`, `failed` |
| Payment provider | `paystack`, `flutterwave` |
| Production wallet provider | `turnkey`, `privy` |
| Production wallet chain | `ethereum`, `solana` |
| Sandbox scenario | `success`, `failure`, `pending`, `insufficient_funds`, `timeout`, `provider_outage` |
| Routing strategy | `best_success_rate`, `lowest_fees`, `fastest_response`, `custom_priority` |

Provider catalog entries can exist without executable capability. Read `GET /v1/providers` and [supported providers](/user-guide/providers) rather than assuming every catalog entry implements these values.
