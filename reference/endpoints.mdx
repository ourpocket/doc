---
title: "API reference"
description: "Implemented project, Sandbox, and stateless provider endpoints."
---

All paths begin with `/v1`.

| Domain | Method and path | Auth |
| --- | --- | --- |
| Projects and connections | `POST/GET /projects`, `GET /provider-catalog`, `POST /projects/{id}/providers/connect`, `GET /projects/{id}/providers` | JWT |
| Checkout and verification | `POST /payments`, `POST /payments/verify`, `POST /refunds`, `POST /refunds/verify` | Project key |
| Sandbox wallets | `POST/GET /wallets`, `POST /sandbox/wallets/{id}/fund`, `POST /sandbox/wallets/{id}/debit`, `POST /sandbox/transfers` | Sandbox key |
| Account resolution | `POST /providers/{provider}/account-resolution` | Live project key |
| Paystack | `/providers/paystack/recipients`, `/payouts`, `/virtual-accounts`, `/virtual-accounts/requery` | Live project key |
| Flutterwave | `/providers/flutterwave/beneficiaries`, `/payouts`, `/virtual-accounts` | Live project key |
| Live overview | `GET /providers/{provider}/overview?from=&to=&page=&limit=` | Live project key |
| Dashboard overview | `GET /projects/{id}/providers/{provider}/overview?from=&to=&page=&limit=` | JWT |

List and status paths append `/{reference}` to the relevant provider namespace. Overview defaults to 30 days and 10 items, caps lists at 100, is uncached, and returns no retained provider activity. The live Swagger reference is available at `/docs`.
