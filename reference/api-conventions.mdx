---
title: "API conventions"
description: "Versioning, amounts, authentication, and stateless live operations."
---

Normalized routes use `/v1` and return the established `{ "data": … }` envelope. Use positive integer minor-unit decimal strings for write amounts; never send floating-point values.

A project key derives the project and environment. `op_test_sk_` runs simulated Sandbox operations only. `op_live_sk_` can call an active, validated production provider connection. Dashboard provider-overview routes use a user JWT and project scope.

Live provider calls are stateless. OurPocket returns the provider result, then discards it. It does not save provider transactions, balances, accounts, payout or recipient data, customer data, webhook payloads, or snapshots. Use a caller-owned provider reference and retain results in your own system.

`X-Request-Id` accepts a UUID. Sandbox writes use `Idempotency-Key`; production writes do not retry automatically.
