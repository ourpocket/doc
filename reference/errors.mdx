---
title: "Errors"
description: "Understand validation, capability, and provider-operation failures."
---

| Status | Code or condition | What to do |
| --- | --- | --- |
| `400` | Invalid input or Production connection missing | Correct the request or validate the selected connection. |
| `401` | Missing, invalid, or revoked project key | Use an active project key. |
| `409` | Sandbox idempotency conflict | Reuse the original body or choose a new key for a new simulated operation. |
| `415` | `capability_unavailable` | Enable the product in the connected provider account or select a supported operation. |
| `502` | Provider response was malformed or unavailable | Query or verify the caller-owned provider reference. Do not repeat the write automatically. |

Provider calls return no stored OurPocket resource. Preserve provider references and returned results in your application for support and reconciliation.
