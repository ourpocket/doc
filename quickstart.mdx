---
title: "Quickstart"
description: "Create a project and run a simulated payment without provider credentials."
---

Create a project in the dashboard and save the `op_test_sk_` Sandbox key returned once. Sandbox is isolated from providers and moves no real money.

<Steps>
  <Step title="Create a project">
    Register, create a project, and save its Sandbox key on your server. You can also call `POST /v1/projects` with your user JWT; the response includes `data.id` and `data.sandboxKey`.
  </Step>
  <Step title="Simulate a payment">
    Amounts are positive integer minor-unit strings. For NGN, `"50000"` means ₦500.

    ```bash
    curl -X POST "$OURPOCKET_BASE_URL/payments" \
      -H "Authorization: Bearer $OURPOCKET_API_KEY" \
      -H 'Content-Type: application/json' \
      -H 'Idempotency-Key: quickstart-payment-1' \
      -d '{"amount":"50000","currency":"NGN","scenario":"success"}'
    ```

    Sandbox returns a simulated resource. Repeat the same request with the same idempotency key to recover it.
  </Step>
  <Step title="Move to a live provider">
    Connect and validate a Production Paystack, Flutterwave, or Mono account. A live checkout accepts a transient `contact`, a caller-owned `reference`, and a callback URL where required. OurPocket returns the hosted URL and discards the provider result after responding.
  </Step>
</Steps>

Use [provider operations](/user-guide/providers) for production collection, payouts, virtual accounts, and the live provider overview.
