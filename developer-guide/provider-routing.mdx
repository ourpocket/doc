---
title: "Selecting a provider"
description: "Choose an explicit active provider for each live operation."
---

Live financial operations require a selected, active, validated provider connection. OurPocket does not automatically fail over or retry a money-moving write.

If a provider request times out, inspect or verify the caller-owned provider reference with that same provider. Preserve the result in your own system. A provider product that is not enabled returns `capability_unavailable`.
