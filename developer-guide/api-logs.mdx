---
title: "API logs"
description: "Inspect local API usage without retaining provider data."
---

API logs show local request metadata such as request ID, route, status, and latency. They do not store provider request bodies, provider response bodies, provider customer data, transaction data, balances, account details, payout data, webhook payloads, or live-overview data.

Use `X-Request-Id` to correlate your own request with local API usage. Keep provider references and operational data in your application and provider dashboard.
