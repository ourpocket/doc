---
title: "Idempotency"
description: "Use idempotency for simulated financial writes and references for live providers."
---

Send `Idempotency-Key` for Sandbox resource creation, funding, debit, and transfers. Repeating an identical Sandbox request returns the same simulated operation; a changed payload returns `409 Conflict`.

Production provider operations are intentionally stateless. Supply and retain your own provider reference where the provider supports one. If a network request times out, query or verify the original provider reference; do not create another financial write automatically. The TypeScript SDK never retries writes.
