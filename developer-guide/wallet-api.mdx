---
title: "Wallet API examples"
description: "Create a Sandbox fiat wallet, fund it, and transfer test funds."
---

Set `OURPOCKET_BASE_URL` to your API's `/v1` URL and `OURPOCKET_API_KEY` to an `op_test_sk_` key. The response payload is inside `data`.

```bash
curl -X POST "$OURPOCKET_BASE_URL/wallets" \
  -H "Authorization: Bearer $OURPOCKET_API_KEY" \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: wallet-example-1' \
  -d '{"currency":"NGN"}'
```

Save `data.id` as `WALLET_ID`. Add simulated funds:

```bash
curl -X POST "$OURPOCKET_BASE_URL/sandbox/wallets/$WALLET_ID/fund" \
  -H "Authorization: Bearer $OURPOCKET_API_KEY" \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: funding-example-1' \
  -d '{"amount":"20000","currency":"NGN"}'
```

`GET /v1/wallets/{id}` returns the updated wallet balance. Create a second wallet with a different idempotency key, then transfer:

```bash
curl -X POST "$OURPOCKET_BASE_URL/sandbox/transfers" \
  -H "Authorization: Bearer $OURPOCKET_API_KEY" \
  -H 'Content-Type: application/json' \
  -H 'Idempotency-Key: transfer-example-1' \
  -d "{\"fromWallet\":\"$WALLET_ID\",\"toWallet\":\"$DESTINATION_WALLET_ID\",\"amount\":\"5000\",\"currency\":\"NGN\"}"
```

For Production, use an `op_live_sk_` key, connect Turnkey or Privy, and create a chain wallet with `{ "provider": "turnkey", "chain": "ethereum" }`. Do not send a fiat `currency`; funding, debit, and internal transfers are Sandbox-only. Read [wallet behavior](/features/wallets) before switching environments.
